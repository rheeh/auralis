# 《雨夜来件》演示与验收记录

本次目标：让小说改编、角色表演和音效编排形成可直接体验、可审查的短篇广播剧 Demo。

## 开始演示

- 浏览器入口：运行前端后打开 `/#/demo`。本次保留的开发服务使用 `http://127.0.0.1:5174/#/demo`，5173 已有其他服务。
- 首页“体验 Demo”和侧栏入口均进入《雨夜来件》。静态构建 `npm --prefix sonicvale-front run build:demo` 包含音频和评测材料，无需模型密钥即可试听、编辑、混音和导出。
- 建议演示顺序：试听完整样片 → 切换同音色无指导版 → 给第 4 句加音效并调音量 → 角色试音 → 提示词实验 → 导出 WAV。
- 当前默认成片 46.22 秒，11 句对白/旁白、7 个音效。所有人声是真实云端合成；小说与导演审定稿为本次原创。电话里的敲门先出现，再由门外重复。

台词改动会使对应预生成音频失效，禁止旧成片播放/导出；可还原本句继续试听，或把小说带入真实工作台重新制作。静态 Demo 不冒充在浏览器里调用了模型。音效、音量和 take 选择会保存到当前浏览器，并实际参与 WAV 导出。

## 本地真实工程

`SonicVale/.venv/bin/python scripts/seed_director_demo.py` 把已生成音频导入独立的“雨夜来件 · 导演Demo”，建立已完成的会话、逐句 take 和时间线，并本地渲染成片。脚本不请求云模型；同名工程已存在时只读返回，不覆盖手工修改。

没有现成 Qwen 配音配置时，脚本只创建停用且不含凭证的离线音色记录。已生成音频可以播放；需要重新配音时，从音色库的“配置 Qwen 广播剧配音”入口保存自己的配置，再绑定音色。

## 现有音频与免费模型

原有 28 个配音/试音文件及 manifest 原样保留，未替换现有角色与逐句版本。新模型试听独立保存在 `free-auditions/` 和 `free-candidates.json`，不改变默认成片。

按照账号控制台核对的免费模型，新增 `qwen-audio-3.0-tts-plus`（龙安灵心、龙安鲁风）和 `qwen-audio-3.0-tts-flash`（龙安风悦）三条短句试音，均真实请求成功并完成解码验证。新组使用同一句话，三条总输入 102 字符；与旧试音组的台词不同，不应当成跨组严格 A/B。

配置中心默认提供新免费语音模型；Demo 新建真实工程仅选择这两个型号的已启用配置，不会自动采用旧收费模型。语音生成脚本拒绝覆盖已有 manifest，需要显式指定新的输出目录。

## 提示词和用量边界

评测默认仅允许 `qwen3.8-27b` 或 `kimi-k3`，不存在其他型号自动回退。Demo 新建改编同样显式选择这两个型号，默认 `qwen3.8-27b`；初始配置模板也已修正。

用户明确型号前，首轮错误使用了 `qwen-plus`；这批历史响应和 token 回执单独保留，不改名、不算成许可型号的结果。指定型号后的新结果及服务商错误见 [提示词实验报告](../evals/audio_drama_v2/REPORT.md)。不能把小样本或模型自评分当作“最佳提示词”的证明。

生产规则保留声音优先、少旁白原则，增加事实落点、人物认知、对白归属、悬念边界、声音先后和可执行分轨约束。独立审查要求指出实际台词证据。配音候选、真实 A/B 及 API 修复详见 [音色报告](voice-audition-2026-09-05.md)。

## 已完成验证

- 真实生成 22 个 A/B take、6 个候选音色试听；文件哈希、文本哈希、完整音频解码通过。
- 浏览器实际播放、同句/整场 take 切换、音效加入、修改台词后的失效保护、WAV 下载通过。
- 浏览器实际导出：44.1 kHz、立体声、46.22 秒 WAV；已用 FFprobe 验证。实时试听与离线导出使用同一混音母线。
- 1440px 桌面及 390px 手机浏览器检查；修复手机嵌套滚动导致内容裁切的问题。
- 8 个 Web Audio 边界测试：时序、全场底声、短素材 seek、取消/销毁、缓存失败重试、立体声编码、实时/离线混音一致。
- 本次全量验证通过：88 项后端单元测试、8 项 Web Audio 测试、8 项评测工具测试，另含 FastAPI 流程和真实音效混音校验。
- 后端全量验证和真实音效混音测试由 `./scripts/verify.sh` 执行；最终测试数量与结果以执行日志为准。

没有进行外部听众盲听，不宣称音色主观质量最佳。现场演示时可以让听众直接选择同文候选。

## 主要实现

- `sonicvale-front/src/pages/DemoStudio.vue`：导演样片、角色试听、评测页面。
- `sonicvale-front/src/demo/audioMixer.js`：真实混音、播放及 WAV 导出。
- `sonicvale-front/src/demo/suspense.json`：原文、审定台本、角色与初始音效。
- `SonicVale/app/core/prompts.py`：编剧与改编约束。
- `SonicVale/app/core/tts_engine.py`：Qwen 指令字段与 CosyVoice 参数、音色能力修正。
- `SoundLibraryPanel.vue` 与 `/sound-library/assets/{id}/insert`：把素材加到任意台词附近，保留现有时间线编辑。

素材来源与许可随静态 Demo 放在 `public/demo-night/sfx/credits.json`。生成音效与开展独立新配音实验分别使用 `scripts/build_demo_effects.py` 和 `scripts/generate_voice_demo.py`；后者默认只打印计划，显式 `--generate` 才请求云端。
