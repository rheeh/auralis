# 最后一盏灯

打烊前，找一串钥匙。

双人生活短剧；单一场景，无旁白。本次成片 1 分 54 秒。

## 人物

- **周岑**：25岁，便利店晚班店员；熟悉阿宁，话少，帮忙时也有点笨手笨脚。
- **阿宁**：26岁，住在附近的常客；刚与室友分开住，今天累了，丢钥匙让她短暂烦躁。

## 表演基调

近距离日常交谈，普通音量，声线与音域稳定。听完对方再回应，短问短答自然接续。着急只让节奏略紧，解围后逐渐松下来；保留普通人的犹豫，不用播音腔，不夸张哭笑。

## 台本

[窗边雨声。店门轻响。]

**周岑**：都关一半灯了。你又忘拿什么？

**阿宁**：钥匙。刚才付钱的时候，我还听见它响。

**周岑**：包放这儿。伞往外挪一点，水要流进抽屉了。

[拉开包袋拉链。]

**阿宁**：这个小袋我翻过了，大的也……没有。

**周岑**：外套呢？

**阿宁**：也找过。你先别问我放哪儿了。

**周岑**：行。你找包，我看柜台下面。

**阿宁**：不是冲你。我今天有点……算了。

**周岑**：要不先叫你室友开门？

**阿宁**：她今天搬走了。备用那把，也还给我了。

**周岑**：哦。两把都在一起？

**阿宁**：嗯。我还觉得这样省事。

**周岑**：先把这盏开着。你从进门开始想，钱掏出来以后呢？

**阿宁**：你找我零钱。我把伞靠在这儿，然后……你是不是擦过柜台？

**周岑**：擦了。还收了几张小票。

[周岑拉开抽屉。里面有很轻的金属碰响。]

**阿宁**：等一下，那个声音。你再拉一下。

**周岑**：抽屉？

**阿宁**：对，里面有东西在响。

[再拉一下抽屉，取出钥匙。]

**周岑**：找着了，压在小票下面。蓝胶带，是你的吧？

**阿宁**：是。两把都在。

**周岑**：我收进去的。刚才还让你翻了半天包。

**阿宁**：你先别道歉。给我，我确认一下。

[阿宁接过钥匙，指间轻响。]

**阿宁**：真是我的。行了，今晚不用找开锁的了。

**周岑**：备用那把，明天分开放。

**阿宁**：知道。你的小票也分开放。

**周岑**：这回记住了。

[钢琴很轻地淡入。]

**阿宁**：我走了。谢谢你啊，周岑。

**周岑**：伞。

**阿宁**：啊？哦，伞。你先别关灯，我在这儿撑开。

**周岑**：慢点，别戳着门。

[店门合上。片刻后，开关轻响。雨声与钢琴淡出。]
